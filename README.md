# UR5-SYSID：UR5 CB3 J0 摩擦與慣量鑑別

以 UR5（CB3）底座關節 J0 為對象，鑑別單軸摩擦與等效慣量，作為關節健康監測（PHM）的基準。

模型：

```
tau = J·qdd + B·qd + Tc·sign(qd),   tau = i × Kt × 101
```

- **定速法**：單一方向、穩態（qdd ≈ 0），多個定速值做線性回歸 → `B`、`Tc`
- **定加速度法**：同一速度下「加速段 − 減速段」消去摩擦 → `J`。10/13 實測減速段摩擦比加速段多一個與加速度無關的常數，故以多個加速度檔做含截距回歸（斜率 = `J`）
- **速度調變法**：巡航速度上疊加正弦速度（速度不歸零、不反向），力矩中與加速度同相的成分 → `J`，與速度同相的成分 → 局部摩擦斜率；以 6 種頻率、振幅檢查 `J` 是否隨頻率或振幅改變（10/22 跑前 4 種，10/29 跑 6 種）。可改在手臂外伸姿態（`POSE = "EXT45"`）執行，比較兩個姿態的 `J`；並記錄控制器的 `target_moment`，得到控制器模型的慣量 `J_model` 作對照。末端加已知質量前後各跑一次時，兩次 `J` 的差應等於 m·r²（r 為質量塊重心離 J0 軸的距離），可直接檢查力矩換算比例
- **J1 定速法**（2026/11 起）：J1 為水平軸，定速時電流含重力力矩；正反轉以定速掃過同一段角度，兩方向合併消去重力 → J1 的 `B`、`Tc`。以手臂朝上（`UP`，窗口中心在重力零點，兩方向受力對稱）為主，診斷原點（`DIAG`）作有負載的對照
- **J1 速度調變法**（2026/11/05 起）：同 J0 速度調變，姿態 `UP`、調變段中心在重力零點；模型多一組重力項（`G_s·sin q + G_c·cos q`）→ J1 的 `J`，並以 `target_moment` 得到控制器的 J1 `J_model` 作對照
- **J2 定速法、J2 速度調變法**（2026/11/09 新增，尚未上機）：J2（肘關節）同 J1 做法。以手臂朝上（`UP`，窗口與調變段中心在 J2 重力零點 −5.7°）為主，診斷原點（`DIAG`，前臂接近水平、重力約 +22.7 N·m）作有負載的對照；J2 的慣量與 J1 角度無關，兩個姿態的慣量相同（官方連桿 + 末端工具約 1.01 kg·m²）

本 repo 只含程式與文件，不含真機量測資料。

J1 是水平軸，定速時電流除了摩擦，還包含撐住手臂重力的力矩 H(q1)。沿用 J0 的固定角度窗口：所有速度、正反轉都以定速掃過同一段 J1 角度（6 個馬達圈 = 21.39°），各段取窗口內的平均，重力項對每一段都相同。每個方向分開回歸 `tau = B·qd + C·d`：正轉 `C₊ = Tc + H̄`、反轉 `C₋ = Tc − H̄`，兩方向合併得 `Tc = (C₊ + C₋)/2` 與窗口平均重力保持力矩 `H̄ = (C₊ − C₋)/2`，不需要連桿質量模型（`combine_directions`）。另記錄控制器的 `target_moment`（官方連桿質量 + 教導器負載的重力模型）；`H̄` 與其窗口平均之比（DIAG）、窗口內兩者對角度的斜率之比（兩個姿態），可作為 J1 換算比例的參考（推測用：前提是控制器的重力模型正確）。

姿態（`POSE`；J0 = 180°，J1 = −90° 時上臂直立，J1 角度減少往後仰、增加往前傾）：

| 姿態 | J2 | 窗口 | 窗口內重力力矩 | J1 活動範圍（FULL） | 法蘭離底座安裝面 | 用途 |
|---|---|---|---|---|---|---|
| `UP`（預設） | 0° | [−102.69°, −81.31°]，中心 −92° = 重力零點 | −12.4～+12.4 N·m，平均 0 | −110.7°～−73.3° | 0.94～1.00 m | 主要 |
| `DIAG` | 90° | [−119.69°, −98.31°] | −0.2～+17.1 N·m，平均 +8.6 | −127.7°～−90°（不低於診斷原點） | 0.43～0.66 m | 有負載的對照 |

- 重力力矩以 UR 官方連桿質量與重心 + 末端工具 1.30 kg 計算。兩個姿態都從 J1 = −90° 開始、結束時回到 −90°。
- 為什麼以 UP 為主：上面的相消假設兩個方向的摩擦一樣大。減速機的摩擦一般會隨傳遞的力矩改變（UR5 的大小未知，推測）。DIAG 窗口內重力都在同一邊，往上抬與往下放的受力不同（以摩擦 12 N·m 估，平均約 21 與 5 N·m），`Tc` 與 `H̄` 會互相混入；UP 窗口內重力正負對稱，兩個方向受力相同，`H̄` 應約為 0，正、反轉各自的 `C` 都應等於 `Tc`，可互相檢查。合成資料（摩擦加上 0.1 × |傳遞力矩|）：UP 的 `H̄` 不受影響，DIAG 的 `H̄` 偏約 9%。兩個姿態的 `Tc` 相比，可看摩擦隨負載改變多少。
- 以摩擦 12 N·m 估，UP 兩個方向的馬達力矩都只在掃過窗口的最後一小段換正負號（減速機受力面換邊），兩方向對稱；DIAG 正轉在窗口後段換邊，反轉不換邊。
- UP 時法蘭離 J1 軸 0.92 m（0.20 rad/s 時法蘭線速度 0.18 m/s），法蘭在 J0 軸後方 0.22 m 到前方 0.36 m 之間，工具尖端最高約 1.05 m。

執行前：

- 以教導器擺好姿態（UP：從診斷原點只把 J2 轉到 0°；J0 = 180°）；確認手臂擺動範圍淨空（UP：底座上方約 1.2 m、底座後方約 0.3 m 以內），J1 附近線材不會被拉扯。
- `POSE` 改成要跑的姿態；填 `J1_SAFE_MIN_DEG` / `J1_SAFE_MAX_DEG`（未設定即中止）：須包含規劃範圍加 2° 餘裕，FULL 時 UP 為 −112.71°～−71.29°（例如 −114、−70），DIAG 為 −129.71°～−88.00°（例如 −131、−87）。
- `PAYLOAD_KG = 1.30`（不夾砝碼）；教導器速度滑桿 100%。程式會要求輸入姿態名稱（`UP` 或 `DIAG`）。

## 敲擊測試（`ur5_tap_test_record.py`）

速度調變量到的 `J` 隨頻率上升（J0 各姿態與 J1 都有）。控制器回報的角度是減速機輸出側，該關節自己的減速機彈性不會改變「力矩 ÷ 輸出側加速度」；剩下的可能之一是輸出側編碼器之後還有彈性（連桿、外側關節、底座或桌子），這需要 7～9 Hz 左右的固有頻率（推測，待這個測試確認）。敲擊後的餘振可以直接讀出固有頻率。

- 程式只讀 RTDE，不會讓手臂動。以教導器擺好姿態、停止所有程式後執行；`POSE` 填姿態、`PAYLOAD_KG` 填教導器負載、`TAP_LABEL` 填敲的方向：
  `none`（不敲，量背景，第一次先跑這個）、`fb`（前後，J1 轉動時工具移動的方向）、`lr`（左右，J0 轉動時工具移動的方向）、`ud`（上下）。
- 記錄 14 s，畫面在第 2、5、8、11 s 提示「敲」，每次敲一下、敲完手離開。敲手腕 3 的金屬外殼或工具法蘭側面，不要敲 FT300、夾爪手指、相機；力道以手臂看得出輕微晃動為準，太大力會觸發保護性停止（那次資料不可用）。
- 輸出 `outputs/taptest_{姿態}_p{負載}_{方向}_{日期}_{時間}/`。分析：

## 備註

- `Kt = 0.135 N·m/A` 與減速比 101 借自文獻數值；`B`、`Tc`、`J` 的絕對值會隨換算比例等比例改變。10/29 以已知質量得到 J0 速度調變的等效換算比例約 10.8 N·m/A（本研究用 0.135 × 101 = 13.64），且隨調變頻率改變（各條件 9.7～11.1），原因未明，尚未用來改寫 `B`、`Tc`。
- 控制器內部的力矩換電流比值（10/22 資料，`target_current` = `target_moment` ÷ 比值 + 摩擦前饋）：J0 為 12.44、J1 為 12.05、J2 為 12.17 N·m/A。
- 控制器 `target_moment` 對應的 J0 慣量 `J_model` = 1.915 kg·m²（常數，與 Gnad 2026 表 3 UR5e 的驅動端慣量相同）+ 官方 DH 頁面連桿點質量 + 教導器負載點質量，兩個姿態、兩種負載設定都成立。實測 `J` 經已知質量校正後與後兩項一致，1.915 在 J0 電流中看不到（見 `analysis/1029/`）。
- 減速比 101 已由資料驗證：以 101 換算馬達角時，各速度檔的電流漣波對齊最好。
