## 2. v3 設計

### 2.1 梯形速度：用「加速 − 減速」直接消去摩擦

每次循環：以加速度 a 爬升到 V_PEAK → 定速 4 個馬達圈（約 1.0 s）→ 以**同樣大小的 a** 線性減速到 0。
同一方向、同一速度 v 下：

- 加速段：`tau_acc(v) =  J·a + f(v)`
- 減速段：`tau_dec(v) = −J·a + f(v)`，其中 `f(v) = B·v + Tc`

因此：

- `J = [tau_acc(v) − tau_dec(v)] / (a_acc + a_dec)`：**摩擦完全相消，不需借用任何 B、Tc**
- `f(v) = [tau_acc(v) + tau_dec(v)] / 2`：**慣性項相消，得到摩擦曲線，可交叉驗證定速法的 B、Tc**
- 定速段力矩 `tau_hold` 應等於 `f(V_PEAK)`：一致性檢查
- 各加速度檔的 `(tau_acc − tau_dec)/2` 對 a 回歸，截距應為 0；若不為 0（或各檔 J 隨 a 變化），代表有模型未涵蓋的項（例如與傳遞力矩相關的摩擦）

減速改用 `speedj` 以同樣 a 降至零速，不再使用 `stopj` 的黑盒煞車曲線（`stopj(a)` 只在最後確保停止）。

**換階段暫態**：v2 資料顯示，換階段後力矩需要數十 ms 才建立到穩定值（a = 2.0 的 40 ms 分析區段整段都在此暫態內）。v3 分析時，每次換階段（靜止→加速、定速→減速）後的前 40 ms 不用（`analyze_const_accel_v3(..., settle_s=0.040)`）。以合成資料加入一階力矩延遲（時間常數 15 ms）測試：不跳過時各檔 $J$ 隨 a 增大而偏低（合併 $J$ = 1.951，−2.4%），跳過 40 ms 後為 1.983（−0.8%）；延遲達 25 ms 時 40 ms 不足（−4%），需依真機資料（$e$ 對換階段後時間作圖）確認此設定。

### 2.2 起始角錯開：讓漣波在重複之間平均掉

第 k 次循環（k = 0…N−1）的起始角往運動方向錯開 k/N 個馬達圈（N = 20 時每次錯開 0.178°，20 次剛好涵蓋一整圈）。每個速度箱在 20 次重複中落在均勻分布的馬達角度上，跟馬達角度鎖定的漣波（每圈 2、5、10、12 次）在平均中抵銷。回程與段間移動仍用 `movej` 絕對定位（v2 已驗證不累積）。

## 6. 10/13 實測結果（定速段 4 個馬達圈，正反轉 FULL 各 1 次）

- 程式行為與規劃一致：80 次循環全部配對；實測範圍正轉 180.0°～209.6°、反轉 150.4°～180.0°；歸位殘差 < 0.004°；實測加速度與指令一致。
- 標準算法各檔 J：正轉 0.24 / 0.98 / 1.23 / 1.44，反轉 0.70 / 1.14 / 1.30 / 1.59（a = 0.3 / 0.6 / 0.9 / 1.2）——**未通過一致性檢查**。
- 原因：`(tau_acc − tau_dec)/2` 對 a 為直線，但截距正轉 −0.50 ± 0.05、反轉 −0.40 ± 0.06 N·m，即**減速段摩擦比加速段多 Δ = 1.0 / 0.8 N·m，且與 a 無關**。以同日定速摩擦為基準的殘差顯示：加速段最低、定速段隨行程上升約 0.3～0.5 N·m、同一行程下減速段又比定速段高約 0.5 N·m。
- 以含截距回歸（截距吸收 Δ）：**J = 1.82 ± 0.10（正轉）、1.86 ± 0.11（反轉）**，兩方向差 2%（v2 為 30%）。換階段後跳過 0～60 ms 時 J 在 1.68～1.86 之間，系統不確定度約 ±0.1。
- 起始角錯開有效：只用加速段（借同日定速摩擦）時，正轉四檔 J = 1.85～1.92，一致。
- 由 `(tau_acc + tau_dec)/2` 得到的摩擦曲線受 Δ 影響（正轉 B = 29.4、Tc = 10.1），不採用。
- 分析程式：`analysis/1013/accel_v3_analysis.py`、`analysis/1013/report_figs_1013.py`。
